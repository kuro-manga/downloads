# Kuro for Android

A manga chapter tracker with a paper-and-ink design. Follow series, track your reading progress, and organize your personal shelf.

## Download

[Download the latest Kuro APK](https://github.com/kuro-manga/downloads/releases/latest)

Requires Android 8.0 or newer.

## Install

1. Open the latest release and download `kuro-1.0.0.apk` from Assets.
2. Open the APK on your Android device. If prompted, allow your browser or file manager to install apps.
3. Confirm installation and open Kuro.

For updates, download the newer APK from this repository and install it over the existing app. Keep your shelf backed up using Kuro’s export option.

## Features

- Follow manga and organize Following, Completed, and Archived shelves.
- See new chapters in Today and track read/unread progress.
- Search for series or add a supported series URL.
- Open available chapter links in your browser.
- Export and import shelf, settings, and activity backups.

Reading takes place on external websites; chapter availability depends on the source.

## Verify your download

Each release includes `SHA256SUMS.txt` so you can check the APK checksum.
